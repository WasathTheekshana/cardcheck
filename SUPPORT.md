# Getting help

- **Something is broken:** [open a bug report](../../issues/new?template=bug_report.yml). Include your browser,
  device, and what you expected to see.
- **A range or length looks wrong:** [open a brand range issue](../../issues/new?template=brand_range.yml) with a
  link to a source.
- **You have an idea:** [open a feature request](../../issues/new?template=feature_request.yml).
- **You want to use the validation code in your own project:** it is MIT licensed. Copy
  [`src/lib/card`](src/lib/card), tests included. Read the notes in the README about accuracy first.
- **Security:** see [SECURITY.md](SECURITY.md).

Please search existing issues before opening a new one. This is a volunteer project, so replies may take a few days.
